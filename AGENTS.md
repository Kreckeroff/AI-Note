# Поставка микрофич

Перед проработкой микрофичи прочитай [контекст продукта](docs/project-context.md), [регламент согласований](docs/workflow/operating-model.md) и [навык поставки микрофич](docs/workflow/skills/microfeature-delivery/SKILL.md).

Для каждой новой микрофичи и каждого пробела в уже описанном поведении запусти отдельного агента-аналитика. Передай ему карточку и связанные артефакты. Через Grilling аналитик сверяет факты, предлагает варианты и формулирует решения, которые нужно принять владельцу. Проведи это обсуждение с владельцем и запиши подтверждённое поведение и проверяемые критерии в карточке микрофичи.

Начинай реализацию после подтверждения старта владельцем для конкретной версии пакета по регламенту согласований.
