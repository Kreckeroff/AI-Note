# Центр фич

Из корня проекта запустите на Node.js 22 или новее:

```sh
node feature-center/server.mjs
```

Доска открывается по адресу [127.0.0.1:4117](http://127.0.0.1:4117). Сервер работает на вашем компьютере. Доступ к записи получают пользователи и процессы с доступом к этому компьютеру. Поле «Автор записи» хранит указанное имя для истории.

В бэклоге находятся продуктовые микрофичи документов и пространств. Стабильный продуктовый ID вида `KB-SPC-01` связывает карточку с её короткой историей и проверками. Известные предпосылки связаны внутри реестра. Оценки, сроки и ответственных назначаем при проработке конкретной микрофичи. [Каталог](../docs/product/documents/README.md) · [Пайплайн](../docs/workflow/operating-model.md#поставка-микрофичами)

В карточке находятся вкладки «Карточка», «Артефакты», «Процесс и QA» и «История». Ссылки на документы из папки docs имеют вид `/docs/workflow/roles.md`. При обновлении значимого документа укажите новую редакцию в карточке. Согласования привязаны к записанным редакциям и содержанию карточки. Завершение релиза фиксирует внешний результат, указанный владельцем или оркестратором.

## Единый реестр

Сохранённые карточки и история лежат в `feature-center/features.json`. Сервер создаёт этот файл при первом запуске. Для резервной копии достаточно скопировать файл. Оркестратор читает его напрямую и записывает изменения через локальный API, чтобы соблюдать проверки, историю и ревизии.

- `GET /api/features` возвращает состояние с номером `revision`.
- `POST /api/features` принимает JSON с полями `action`, `author`, `revision`, а для существующей карточки также `id`.
- Действия `create` и `update` принимают `data` с полями карточки. Действие `move` принимает `status`, а для перехода в `released` также `evidence`. Действие `approve` принимает `gate` и `note`. Действие `qa` принимает `report`. Действие `close` принимает `note` и переводит карточку в статус «Закрыта» по решению владельца. Этот статус завершает работу по карточке и сохраняет её историю.
- При конфликте ревизий сервер возвращает 409 с актуальным состоянием. Сверьте его с исходным и повторите применимые изменения. Отказ правила процесса возвращается с кодом 422.

Чтобы увидеть изменения, внесённые через API, вернитесь на вкладку доски или перезагрузите страницу. При конфликте во время редактирования форма сохраняет введённый текст до закрытия.

## Планирование

Роадмапа показывает горизонты, даты и задачи на сегодня по московскому времени. Критический путь вычисляется для обязательного незавершённого объёма с его предпосылками, в относительных днях. Для расчёта заполните «Осталось дней» у каждого элемента этого объёма. Доступность ресурсов, выходные и календарные ограничения при этом не учитываются.

Проверки процесса и реестра запускаются командой `node --test feature-center/*.test.mjs`.

## Локальный просмотр в macOS

В текущем входе macOS доска и просмотр макетов запущены через пользовательский launchd.
Имена заданий — `local.sever-roadmap` и `local.sever-design-preview`. Оба слушают 127.0.0.1 и работают при паузе в чате.
Для остановки используйте `launchctl remove local.sever-roadmap` или `launchctl remove local.sever-design-preview`.
После нового входа можно воспользоваться командами запуска проекта. [Макеты](http://127.0.0.1:4120/design/#atlas/graph/access).
