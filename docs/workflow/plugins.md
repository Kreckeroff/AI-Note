# План плагинов и подключений

Проверено 17 ноября 2026 года по локальной конфигурации, доступному каталогу навыков и поиску плагинов. `installed=true` в каталоге не доказывает права на каждый репозиторий/файл и работоспособность всех операций.

## База, которой уже достаточно для проектирования процесса

В локальной конфигурации включена 31 запись плагинов, 25 уникальных названий. Arxitect, Backend Design, Clean Architecture, Design, Matt Pocock Skills и QA Bug Hunter повторяются из двух источников. Для одной задачи выбирать одну версию навыка и проверять её инструкции.

Доступные наборы покрывают аналитику/продукт (Product Management, Matt Pocock Skills), архитектуру (Engineering, Arxitect, Clean Architecture), реализацию (Backend Design, Frontend Design), дизайн (Design, Design Skills, Figma), проверку (QA Bug Hunter, Engineering), данные, документы и визуализацию. Конкретные навыки перечислены в skill-catalog.md.

| Подключение | Подтверждённое состояние | Роль в процессе |
|---|---|---|
| GitHub | Установлен; базовая авторизация ранее успешно проверена | Репозитории, изменения, PR, задачи и CI при наличии прав |
| Figma | Установлен; базовая авторизация ранее успешно проверена | Макеты, прототипы и дизайн-хэндоффы |
| Sites | Каталог подтверждает установку | Размещение доски/прототипа при выборе этого способа и разрешении публикации |
| Confluence MCP | Записан в конфигурации, успешный запрос не подтверждён | Возможный источник спецификаций, если владелец выберет его |
| Teamstream MCP | Записан в конфигурации, успешный запрос не подтверждён | Отношение к новому продукту пока не установлено |

Проверки профилей внешних сервисов ради общего списка не повторяются. Работоспособность нужного ресурса проверяется, когда он участвует в конкретной задаче.

## Найденные дополнения

Все ниже перечисленные кандидаты были возвращены доступным каталогом, но не установлены по последней проверке.

| Плагин | Когда полезен | Решение для старта |
|---|---|---|
| Linear | Общий backlog, задачи, проекты, синхронизация статусов | Выбрать при потребности во внешнем трекере; альтернатива локальному реестру/GitHub Issues |
| Notion | Совместная база требований и решений | Выбрать, если это рабочая база команды; определить владение полями и синхронизацию |
| Atlassian | Jira/Confluence и связанные процессы | Выбрать при использовании этой экосистемы; не путать с уже настроенным отдельным Confluence MCP |
| Product Design | Исследование направлений, прототипирование и проверка UX | Кандидат для роли дизайнера; оценить добавленную пользу к существующим Figma/дизайн-навыкам |
| Superpowers | Планирование, TDD, отладка и совместная работа агентов | Изучить выборочно: пересекается с Matt Pocock/Engineering и не заменяет проектные согласования |
| OpenAI Developers | Разработка ИИ-приложений и агентов | Полезен, если проект включает собственное агентское приложение/интеграцию OpenAI |
| PostHog | Продуктовая аналитика, flags, эксперименты, ошибки и LLM-аналитика | После определения метрик и способа эксплуатации продукта |
| Datadog | Метрики, логи, трассировки и расследование инцидентов | При использовании сервиса в инфраструктуре |
| Vercel | Размещение веб-приложения | После выбора стека и платформы выпуска |
| Firebase | Backend-сервисы и размещение | После выбора архитектуры |
| Redis | Практики использования Redis и памяти агентов | При реальной необходимости Redis; наличие плагина само по себе не выбирает хранилище |

Первые два ранее предложенных дополнения — Superpowers и OpenAI Developers — всё ещё отмечены неустановленными. Их нельзя считать действующими зависимостями процесса.

## Тестовые инструменты

Unit/component/integration/E2E-тесты и проверки инъекций не требуют отдельного ChatGPT-плагина для каждого уровня: исполнитель использует реальные инструменты выбранного проекта через CLI, CI и доступные браузерные возможности. Сначала определяется стек и существующий test runner, затем способ запуска.

Поиск точных названий Playwright и Sentry не вернул соответствующих плагинов. Поиск Codex Security также не вернул однозначного совпадения; из этого не следует, что таких интеграций вообще нет. Дополнительные варианты могут быть в [каталоге плагинов](https://chatgpt.com/plugins). Playwright как библиотека/CLI или MCP — отдельный способ подключения, который требуется проверить при настройке UI-тестов.

Встречающийся в QA Bug Hunter пример установки MCP через Claude CLI не является проверенной инструкцией для этой среды Codex. Его нельзя переносить в настройки автоматически.

## Правило добавления

Новый плагин закрывает конкретную потребность роли или доступ к выбранному сервису. Для каждого фиксировать: сценарий, ожидаемые инструменты, состояние установки, состояние авторизации и рабочий ресурс. Скиллы и плагины можно добавлять по мере первого применимого сценария, сохраняя совместимость основного процесса.
