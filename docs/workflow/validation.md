# Проверка проекта процесса

17 ноября 2026 года проведён независимый сценарный разбор в новом контексте без наследования обсуждения. Это проверка согласованности документов; продуктовый код и реальная работа будущего runtime не тестировались.

| Входная ситуация | Установленный маршрут |
|---|---|
| Спецификация есть, согласование её редакции отсутствует | Предъявить конкретный пакет и зафиксировать адресное подтверждение до реализации |
| После старта предлагается изменить публичное API | Обновить контракт, определить влияние и пересогласовать затронутые решения |
| QA не нашёл дефектов, но обязательная интеграционная проверка не выполнена | Сохранить блокировку; допуск к выпуску не выдавать |
| Три раунда повторяют дефект без прогресса | Сохранить незавершённый статус и вынести владельцу решение о причине тупика |
| Владелец просит исправить баг, QA его подтвердил | Разработчик получает задачу: постоянный регрессионный тест → исправление → новый QA |
| Push может запускать production-deploy | Учесть этот эффект в согласовании выпуска конкретной версии |
| Приоритеты известны, длительности нет | Показать зависимости; критический путь и срок оставить нерассчитанными |
| Заняты все четыре агентских слота | Очередь либо checkpoint и освобождение слота перед новым запуском |

Выявлено и исправлено несовместимое назначение Diagnosing Bugs независимому QA: навык включает инструментирование и исправление, поэтому его основная роль изменена на разработчика. Каталог и структурированный реестр обновлены вместе.

Дополнительно уточнено сравнение состояния файлов до и после QA: исходные изменения разработчиков относятся к проверяемому снимку и не считаются действиями проверяющего. Для вложенных обзоров явно описаны очередь и общий предел агентских слотов.

Локальная проверка подтвердила 77 уникальных записей и наличие каждого указанного SKILL.md, а также разрешение относительных и абсолютных файловых ссылок в документах. Работоспособность внешних плагинов и поведение будущих новых скиллов этим не подтверждаются.
