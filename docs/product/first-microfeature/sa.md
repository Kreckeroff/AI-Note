## Контракт и данные

Контекст пространств принимает название и берёт субъект из действующей сессии. На организационной установке сервер проверяет право создания, выданное в пределах этой организации. Для проверки микрофичи используются подготовленные аккаунты с правом и без него. В установке без организации достаточно действующей сессии. Управление правом вынесено в [KB-AUTH-17](../documents/access/kb-auth-17.md).

Результат успешной операции — устойчивый ID, название и открытие области владельцем. Название после удаления крайних пробелов содержит от 1 до 100 символов и уникально среди пространств владельца. Предлагаем сравнивать Unicode-названия без учёта регистра, сохраняя регистр отображения. Сервер проверяет ограничение при записи, в том числе при одновременных запросах. Повтор одной отправки возвращает исходный результат, а новая отправка с уже занятым именем показывает ошибку и сохраняет введённое название.

При чтении сервер проверяет право на конкретное пространство по ID аккаунта из сессии KB-AUTH-01. Роль администратора организации даёт право просмотра всех её пространств. Редактирование проверяется по полномочиям на конкретное пространство. Создание пространства и членства владельца выполняются одной транзакцией SQLite на локальной установке. После создания открывается пустая страница по устойчивому адресу. Поиск и выдача каталога входят в [KB-SPC-02](../documents/spaces/kb-spc-02.md), а организационный обзор доступа — в [KB-ACL-20](../documents/sharing/kb-acl-20.md). Операции с правами фиксируют субъект, область и результат без записи содержимого или учётных данных. [Техническая SA входа](../documents/access/kb-auth-01-sa.md)

## Исходы и проверки

| Проверка | Предусловие и действие | Наблюдаемый результат |
|---|---|---|
| К1 · Создание | Аккаунт A с правом создаёт «Документы команды» | Открывается пустая область. A может открыть её по тому же адресу после выхода и нового входа. |
| К1 · Повтор отправки | Одна операция отправлена повторно после потери ответа | Сохраняется один результат. Интерфейс возвращает ссылку на созданную область. |
| К3 · Чтение чужой области | Обычный участник без доступа открывает прямой адрес | Название и содержимое недоступны, чтение отклонено на сервере. |
| К3 · Чтение администратором | Администратор той же организации без членства открывает прямой адрес | Страница закрытого пространства открывается в режиме просмотра. |
| К2 · Операция без права | Аккаунт без права создания отправляет форму или прямой запрос | Возвращается отказ, новый объект отсутствует. |
| Дублирование названия | Владелец отправляет новый запрос с названием существующего пространства | В форме видна ошибка, новое пространство не появляется, введённое название сохранено. |
| Ошибка формы | Пользователь отправляет пустое название либо запись завершается сбоем | UI показывает состояние ошибки, сохраняет ввод и допускает исправление или повтор. |

Проверки прав и повтора проходят на публичной границе сервиса. UX проверяется в пользовательском интерфейсе с реальными аккаунтами на фиксированной версии. Реализация и QA отражают фактические проверки и результаты по ID.
