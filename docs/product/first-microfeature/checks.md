# KB-SPC-01 · План проверок

Черновик 0.1. [История](../documents/spaces/kb-spc-01.md) · [Контракт](sa.md)

Проверить на изолированной базе с двумя участниками с правом создания, одним участником без этого права и администратором организации. Проверки записи и доступа идут через публичный HTTP-интерфейс. Форму и состояние пространства проверяем в браузере.

| Сценарий | Ожидаемое поведение |
|---|---|
| Создание и повторный вход | Владелец видит пустую страницу с названием и открывает её по тому же адресу после повторного входа |
| Недействующая сессия или отсутствие права в организации | Сервер отклоняет создание. У участника без права нет кнопки. Новое пространство отсутствует |
| Право просмотра | Обычный участник без доступа не получает имя или содержимое по прямой ссылке. Администратор той же организации открывает пространство для просмотра |
| Границы названия | 1 и 100 символов после обрезки допустимы. Пустое, слишком длинное и совпадающее у владельца имя отклоняются. Два разных владельца могут сохранить одинаковое имя |
| Сбой, повтор и параллельная запись | Повтор одной отправки даёт один результат. Два новых запроса с одинаковым именем одного владельца не создают два пространства. Введённое название сохраняется при ошибке |
| Установка без организации | Вошедший пользователь создаёт пространство в рамках правил самостоятельной установки |
| Клавиатура и узкий экран | Форма, ошибки и пустая страница читаются без горизонтальной прокрутки. Диалог и его поля доступны с клавиатуры |
