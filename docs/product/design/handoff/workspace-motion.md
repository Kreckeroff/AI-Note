# Отклик рабочего пространства и схема AI · версия 1.0

**Сценарий.** Участник открывает AI-подход, видит вход, источник и порядок получения результата, выбирает шаг и открывает его свойства. Владелец пространства меняет требование ссылки на источник. Настройка определяет, можно ли запустить подготовку черновика по выбранной задаче. [Прототип](../sever-prototype/approach.mjs) · [AI-01](../../work-areas/ai-01.md) · [Аудит](../../notion-workspace-audit.md)

| Решение | Критерий |
| --- | --- |
| Проверка ссылки происходит до передачи запроса модели. | При включённой проверке видны семь шагов. При выключенной — шесть. Ссылка на отключённый шаг открывает инструкцию. |
| На широком экране линия соединяет выход карточки с входом следующей, в том числе между рядами. На телефоне последовательность идёт сверху вниз. | Выбор шага с клавиатуры сохраняет выбранную задачу, помечает единственный текущий шаг и переводит фокус к его свойствам. На узком экране есть обратный переход. |
| Тип шага передаётся текстом, исходной иконкой и цветом. Главное название экрана описывает запускаемый процесс. | Человек различает вход, условие, генерацию, подтверждение и результат в обеих темах. Флажок проверки имеет размер 17 × 17 px, работает также нажатие на его подпись. |
| Панели открываются за 160 мс. Кнопки и карточки отвечают на наведение и фокус без ожидания конца анимации. | Поиск можно сразу использовать и закрыть Escape. Диалоги сохраняют центрирование. С системным уменьшением движения панели открываются сразу, задача при наведении остаётся на месте. |

Владелец поручил реализовать исправления самостоятельно 21 ноября 2026 года. Порядок шагов выбран по фактической серверной проверке источника. Сервер уже проверяет доступ и условия запуска. Схема рендерится из этого же признака и сохраняет рабочие ссылки без JavaScript. [Представление](../../../../backend/src/approach_http.rs) · [Правила запуска](../../../../backend/src/db/approaches.rs)

Проверено в отдельном Docker-кандидате с PostgreSQL 16. Регрессионный тест Rust проверил порядок шагов в двух конфигурациях, сохранение задачи в URL и выбор доступных свойств по прямой ссылке. Chrome прошёл 1360, 390 и 320 px, обе темы, фокус по Enter, возврат из свойств и открытие поиска через Ctrl+K. При 390 px с уменьшенным движением у диалога отсутствовала анимация. Во всех трёх случаях подпись переключала флажок, ширина страницы совпала с окном.
