Первый реальный прогон TeamStream остановился на ожидании взаимодействия с закрытым плеером. Прошли 111 тестов Rust и PostgreSQL и 93 теста React и TypeScript. Независимый QA подтвердил открытие поиска сочетаниями `⌘K` и `Ctrl+K`. Первый Escape закрывает диалог с введённым запросом, возвращает фокус и сохраняет адрес страницы.

## Границы версии

- Экран организации показывает состояние SSO. Подключение корпоративного провайдера и фирменные цвета остаются отдельными задачами.
- В AI-подходе выполняется сценарий подготовки спецификации с согласованием владельцем. История журнала указывает редакцию источника, ссылка ведёт к текущей странице.
- На исторической шкале графа участник без права просмотра редакций видит документ с даты текущей редакции.
- Шапка переходит в два ряда до 1100 px. В обложке рабочей страницы выводятся метки доступа, поле подзаголовка пока отсутствует. В строке под обложкой выводится номер редакции, имя автора доступно в истории редакций.
