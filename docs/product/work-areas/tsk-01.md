# TSK-01 · Создать задачу в пространстве

Черновик · [Рабочие разделы](README.md)

## История

Участник с правом создания хочет записать работу команды.

## Приёмка

- **К1.** Новая задача получает устойчивый ID и появляется в выбранном доступном пространстве после обновления.
- **К2.** Отказ или повтор запроса не создают лишнюю задачу.
