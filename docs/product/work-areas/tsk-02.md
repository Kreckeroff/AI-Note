# TSK-02 · Открыть Kanban пространства

Черновик · [Рабочие разделы](README.md)

## История

Участник хочет видеть доступные задачи сгруппированными по статусам.

## Приёмка

- **К1.** Доступные задачи показаны в своих колонках. Счётчики совпадают с видимыми карточками.
- **К2.** Пустая колонка и отсутствие доступа имеют разные состояния. Закрытые карточки не попадают в счётчик.
