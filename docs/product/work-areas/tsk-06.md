# TSK-06 · Открыть задачи списком

Черновик · [Рабочие разделы](README.md)

## История

Участник хочет просматривать те же задачи в компактной очереди.

## Приёмка

- **К1.** Переключение из Kanban открывает тот же доступный набор задач списком. Карточка открывается из любого представления.
- **К2.** Выбранный фильтр сохраняется при смене представления. Пустая выдача имеет отдельное состояние.
