# KB-TREE-04 · Увидеть путь к открытому материалу

## История

**Читатель** хочет понять, где находится страница, открытая по ссылке.

## Приёмка

- **К1.** Текущая страница выделена, доступные предки показаны в порядке вложенности и открываются из пути.
- **К2.** Недоступный предок не раскрывает своё имя.
