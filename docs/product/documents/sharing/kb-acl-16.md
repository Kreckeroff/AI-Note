# KB-ACL-16 · Запросить доступ к странице

Требования и макет 1.0 согласованы · [Шеринг и права](README.md)

## История

**Сотрудник** хочет получить право чтения у ответственного.

## Приёмка

- **К1.** Действующий участник текущего тенанта запрашивает просмотр с нейтрального экрана. До выдачи скрыты содержимое и метаданные закрытой страницы.
- **К2.** Владелец получает запрос только для существующей страницы того же тенанта. Повтор сохраняет максимум одно открытое обращение. Неизвестный и чужой адрес дают нейтральный ответ.
- **К3.** Одобрение даёт просмотр по тому же адресу. Отклонение завершает обращение без выдачи права.
