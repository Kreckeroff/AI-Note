# KB-ACL-16 · Запросить доступ к странице

Черновик · Развитие блока · [Шеринг и права](README.md)

## История

**Сотрудник** хочет получить право чтения у ответственного.

## Приёмка

- **К1.** Из экрана отказа уходит запрос с ID ресурса и заявителя ответственному.
- **К2.** До выдачи права заявитель не получает содержимое, повтор отображает открытый запрос.
