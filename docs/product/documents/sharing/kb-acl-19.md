# KB-ACL-19 · Изменить состав группы

Черновик · Развитие блока · [Шеринг и права](README.md)

## История

**Администратор** хочет добавлять и удалять участников по мере изменения команды.

## Приёмка

- **К1.** Список участников сохраняется после обновления.
- **К2.** Удаление участника пересчитывает групповые права там, где группа уже назначена.
