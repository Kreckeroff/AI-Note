# KB-ACL-11 · Отключить публичную ссылку

Черновик · Развитие блока · [Шеринг и права](README.md)

## История

**Владелец страницы** хочет прекратить доступ внешних читателей.

## Приёмка

- **К1.** Выданный адрес перестаёт открывать страницу и ресурсы, доступные по нему.
- **К2.** Внутренняя ссылка продолжает работать для уполномоченных участников.
