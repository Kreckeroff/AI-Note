# KB-ACL-06 · Дать человеку просмотр отдельной страницы

Черновик · Базовый контур · [Шеринг и права](README.md)

## История

**Владелец страницы** хочет поделиться конкретным документом.

## Приёмка

- **К1.** Указанный получатель открывает страницу по ссылке и читает её.
- **К2.** Доступ не раскрывает соседние документы, редактирование отклоняется.
