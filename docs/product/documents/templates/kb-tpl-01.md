# KB-TPL-01 · Создать страницу из готового шаблона

Черновик · Развитие блока · [Шаблоны страниц](README.md)

## История

**Редактор** хочет начать типовой документ с согласованной структуры.

## Приёмка

- **К1.** Созданная страница получает исходное содержимое и ссылку на использованную редакцию шаблона.
- **К2.** Последующие правки страницы не изменяют шаблон.
