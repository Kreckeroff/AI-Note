# KB-UI-02 · Открыть инспектор страницы

Требования и макет 1.0 согласованы · [Интерфейс и настройки](README.md)

## История

**Читатель** хочет увидеть свойства документа рядом с текстом.

## Приёмка

- **К1.** Инспектор показывает «Контекст» с данными текущей страницы, «Комментарии» по праву чтения и «Историю» по праву редактирования.
- **К2.** На широком экране открывается правая панель, на узком диалог. Вкладки и закрытие сохраняют позицию и черновик, Escape возвращает фокус.
- **К3.** Прямой переход к ветке открывает «Комментарии», ссылка на снимок работает как прежде. Публичное чтение открывается без инспектора.
