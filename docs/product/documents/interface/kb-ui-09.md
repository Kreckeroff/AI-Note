# KB-UI-09 · Применить форматирование клавиатурой

Черновик · Развитие блока · [Интерфейс и настройки](README.md)

## История

**Редактор** хочет выделить текст без переключения на панель инструментов.

## Приёмка

- **К1.** Назначенные клавиши применяют жирный или курсив к текущему выделению, формат виден в редакторе.
- **К2.** Фокус остаётся в тексте, глобальное действие браузера не перебивает согласованную команду.
