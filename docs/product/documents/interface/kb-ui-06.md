# KB-UI-06 · Сохранить документ сочетанием клавиш

Черновик · Развитие блока · [Интерфейс и настройки](README.md)

## История

**Редактор** хочет подтвердить сохранение без перехода к кнопке.

## Приёмка

- **К1.** Сочетание сохраняет текст и показывает состояние операции, как кнопка сохранения.
- **К2.** При отказе введённый текст остаётся доступен для повтора.
