# KB-UI-11 · Вернуться к предыдущему экрану

Черновик · Развитие блока · [Интерфейс и настройки](README.md)

## История

**Участник** хочет переходить назад и вперёд по рабочим экранам через верхнее меню.

## Приёмка

- **К1.** «Назад» и «Вперёд» доводят до прежнего доступного объекта. На границе истории соответствующее действие недоступно.
- **К2.** Новый переход после возврата заменяет прежнюю ветку вперёд. Отозванный доступ не раскрывает объект из истории.
