## История

**Участник** хочет открыть поиск, не отрываясь от документа.

## Приёмка

- **К1.** Назначенные сочетания на macOS и Windows открывают поиск и ставят фокус в поле.
- **К2.** После Escape фокус возвращается к прежнему элементу.
