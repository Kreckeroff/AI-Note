## История

**Читатель** хочет перейти к другой странице при ограниченной ширине.

## Приёмка

- **К1.** Дерево открывается по запросу, переход возвращает к содержанию выбранной страницы.
- **К2.** Фокус и элементы чтения доступны после закрытия панели.
