# KB-UI-10 · Выбрать тип создаваемого материала

Черновик · Развитие блока · [Интерфейс и настройки](README.md)

## История

**Участник** хочет начать создание нужного материала из верхнего меню.

## Приёмка

- **К1.** По «Создать» открываются карточки доступных и реализованных типов. Выбор страницы или раздела переводит в соответствующую форму с текущим местом; задача появляется вместе с контекстом задач.
- **К2.** Выбор карточки и закрытие диалога не создают объект. Клавиатурный фокус возвращается к кнопке при закрытии.
