# KB-FIL-08 · Загрузить свою обложку страницы

Черновик · Развитие блока · [Вложения и медиа](README.md)

## История

**Редактор** хочет использовать изображение команды в оформлении страницы.

## Приёмка

- **К1.** Поддерживаемый файл появляется в предпросмотре и сохраняется вместе с редакцией. Загрузку содержимого файла получают только читатели с соответствующим доступом.
- **К2.** Неподдерживаемый, повреждённый, слишком большой файл или ошибка загрузки оставляют предыдущую обложку и черновик текста.
