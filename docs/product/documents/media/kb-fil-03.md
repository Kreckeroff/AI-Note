# KB-FIL-03 · Удалить вложение со страницы

Редакция 1.0 · Требования подтверждены · [Пакет](../editor/kb-page-attachments-start.md) · [Вложения и медиа](README.md)

## История

**Редактор** хочет убрать ошибочно прикреплённый материал.

## Приёмка

- **К1.** Если у файла есть вставки, подтверждение показывает их число. Действие убирает файл и все его вставки из черновика. Файл без вставок удаляется из черновика сразу. Общее сохранение публикует итог и сохраняет другие файлы и текст.
- **К2.** При удалении отдельной вставки файл остаётся в списке. Отмена черновика, конфликт и сбой сохраняют опубликованные данные.
- **К3.** После публикации удаления текущий URL закрывается. Редактор с действующим доступом открывает файл из старого снимка. Восстановление возвращает файл по новому текущему адресу, сохраняя старый снимок.
