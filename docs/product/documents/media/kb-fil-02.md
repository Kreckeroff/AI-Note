# KB-FIL-02 · Скачать вложение

Черновик · Развитие блока · [Вложения и медиа](README.md)

## История

**Читатель с правом скачивания** хочет использовать прикреплённый материал.

## Приёмка

- **К1.** Разрешённому пользователю скачиваются исходные байты файла с согласованным именем.
- **К2.** Скопированный URL без действующих прав не выдаёт содержимое.
