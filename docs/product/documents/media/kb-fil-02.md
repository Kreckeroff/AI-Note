# KB-FIL-02 · Скачать вложение

Редакция 1.0 · Требования подтверждены · [Пакет](../editor/kb-page-attachments-start.md) · [Вложения и медиа](README.md)

## История

**Читатель страницы** хочет использовать прикреплённый материал.

## Приёмка

- **К1.** По действующему праву чтения скачиваются исходные байты опубликованного файла с корректным именем, в том числе с кириллицей.
- **К2.** Скопированный URL повторно проверяет право и страницу. После отзыва права, при неподходящем тенанте или при удалении текущего вложения возвращается `404` без имени и байтов.
- **К3.** Доступ к файлу прежней редакции проверяется по праву на историю и именно для указанного снимка.
