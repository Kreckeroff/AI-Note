# KB-FIL-05 · Вставить внешнее изображение

Черновик · Развитие блока · [Вложения и медиа](README.md)

## История

**Редактор** хочет показать изображение по разрешённому адресу.

## Приёмка

- **К1.** Поддерживаемый адрес отображается с указанным альтернативным текстом.
- **К2.** Недоступный ресурс имеет читаемое состояние и исходник сохраняется.
