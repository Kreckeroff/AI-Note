# KB-PAG-01 · Пакет создания страницы

Редакция 1.0 · 18 ноября 2026 года · FC-022 · согласована владельцем

## Что получит пользователь

Владелец пространства или назначенный редактор открывает раздел и нажимает «Добавить страницу». Диалог «Новая страница» показывает текущий раздел и поле «Название». При успехе страница появляется в конце списка раздела. Дерево раскрывает родителя, выделяет новую строку, а документ открывается в режиме чтения с введённым заголовком и пустым содержимым.

При ошибке название остаётся в форме. «Отмена» и Escape возвращают к исходному разделу и фокусу на «Добавить страницу». Читатель и администратор с правом просмотра видят дерево и доступные страницы. Право на создание применяется к владельцу и назначенному редактору с активным членством.

[Макет «Онбординг»](http://127.0.0.1:4120/design/sever-prototype/#doc/onboarding) показывает путь «Добавить страницу» → название → новая страница. В этом пакете расположение фиксировано открытым разделом. [Хэндофф редактора](../../design/handoff/editor.md)

**Правило имени.** От 1 до 100 символов после удаления крайних пробелов. Названия уникальны среди страниц одного раздела после нормализации Unicode NFC и приведения к нижнему регистру. В других разделах то же название допустимо.

## Технический контракт

- Форма открывается по `GET /workspace/{tenantId}/spaces/{spaceId}/sections/{sectionId}/pages/new`. Раздел и право на запись проверяет Rust. Запись выполняется через `POST` на коллекцию без суффикса `/new` с проверкой Origin.
- PostgreSQL атомарно сохраняет страницу и результат операции. Страница получает UUID, принадлежит разделу этого пространства, содержит автора, название, порядок и пустой Markdown. Точный повтор отправки открывает ту же страницу. Две параллельные успешные отправки с разными именами дают две строки с устойчивым порядком.
- После сохранения `303` ведёт на канонический адрес `/workspace/{tenantId}/spaces/{spaceId}/pages/{pageId}`. Адрес использует UUID страницы. Текущий раздел берётся из базы, поэтому последующее перемещение внутри пространства сможет сохранить адрес.
- Неверное имя возвращает `422`, конфликт имени или операции — `409`. При временном сбое `503` сохраняет ввод и ключ операции. Читатель получает `403` на запись, чужая среда или недоступный раздел — нейтральный `404`.
- React и серверный HTML получают выбранную страницу и дерево из одного разрешённого набора. Параметры поиска, фильтра и пагинации каталога сохраняются при навигации. Срез включает чтение пустой страницы по её адресу после создания и обновления. [KB-PAG-02](kb-pag-02.md) покрывает вход получателя по ссылке, текущую доступную редакцию и открытие первой доступной страницы из каталога. Изменение текста идёт в [KB-MD-01](../editor/kb-md-01.md).

## Проверки

| Проверка | Ожидаемый результат |
|---|---|
| Создание и обновление | Владелец и редактор создают страницу в текущем разделе. Родитель раскрыт, страница выделена. После обновления название, URL и порядок сохраняются. |
| Права и границы | Право перепроверяется при записи. Прямой запрос читателя и администратора с одним просмотром отклонён. Раздел чужого тенанта даёт нейтральный ответ. |
| Название и Unicode | Границы длины, пробелы и нормализация проверены. Совпадение имени внутри раздела показывает ошибку, то же имя в другом разделе сохраняется. |
| Параллельность и восстановление | Точный повтор ведёт на тот же UUID. После временной ошибки введённое название и ключ остаются для безопасного повтора. |
| Диалог и клавиатура | Фокус на названии. Отмена и Escape возвращают к разделу и кнопке создания. На узкой ширине доступны поле, сообщение и действия. |
| Миграция | На копии PostgreSQL сохраняются существующие пространства, разделы, сессии и прямые ссылки. |
