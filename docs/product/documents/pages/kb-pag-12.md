# KB-PAG-12 · Выбрать готовую обложку страницы

Редакция 1.0 · Требования подтверждены · [Страницы](README.md)

## История

**Редактор** хочет оформить страницу одним из готовых вариантов.

## Приёмка

- **К1.** Галерея в обоих режимах показывает «Орбиту», «Сияние», «Картографию» и отмечает текущий выбор. Выбор обновляет предпросмотр и возвращает фокус к кнопке обложки.
- **К2.** Сохранение публикует обложку и исходник одной редакцией, в том числе при изменении только темы. Читатель видит результат по прежней ссылке с JavaScript и без него.
- **К3.** Закрытие галереи сохраняет предыдущий выбор в черновике, отмена редактирования возвращает к опубликованной странице. При `409` и `503` остаются текст и обложка черновика. При двух разных изменениях редактор выбирает вариант перед повторным сохранением.
