# KB-PAG-07 · Отправить страницу в корзину

Черновик · Развитие блока · [Страницы](README.md)

## История

**Владелец** хочет убрать документ из активной базы с возможностью возврата.

## Приёмка

- **К1.** После подтверждения страница скрывается из навигации и открывается уполномоченному пользователю из корзины.
- **К2.** Обычная ссылка показывает согласованное недоступное состояние.
