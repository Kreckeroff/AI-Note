# KB-PAG-02 · Открыть страницу по стабильной ссылке

Черновик · Базовый контур · [Страницы](README.md)

## История

**Читатель** хочет поделиться точным местом в базе знаний с коллегой.

## Приёмка

- **К1.** Прямая ссылка открывает текущую доступную редакцию той же страницы.
- **К2.** Недоступный адрес не раскрывает название и содержимое.
