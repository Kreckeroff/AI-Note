# KB-PAG-09 · Архивировать опубликованную страницу

Черновик · Развитие блока · [Страницы](README.md)

## История

**Редактор** хочет исключить устаревший документ из обычной работы и оставить его для справки.

## Приёмка

- **К1.** Архивная страница читается по прежней ссылке с пометкой об архиве.
- **К2.** Активная навигация не предлагает архивную страницу по умолчанию.
