# KB-AUTH-09 · Зарегистрироваться по почте

Черновик · Развитие блока · [Вход и учётные записи](README.md)

## История

**Новый пользователь** хочет создать локальную учётную запись без обращения к администратору.

## Приёмка

- **К1.** При разрешённой регистрации подтверждение адреса завершает создание одного аккаунта и открывает авторизованную сессию.
- **К2.** Повтор неподтверждённого запроса допускает завершение регистрации. Просроченное подтверждение и выключенная регистрация не создают аккаунт.
