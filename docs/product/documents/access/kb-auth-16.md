# KB-AUTH-16 · Настроить корпоративный провайдер SSO

Черновик · Развитие блока · [Вход и учётные записи](README.md)

## История

**Администратор установки** хочет предложить сотрудникам подтверждённый корпоративный вход.

## Приёмка

- **К1.** После проверки настроек доступный провайдер появляется на экране входа. Корпоративная кнопка скрыта при отсутствии активной конфигурации.
- **К2.** Неверные или неполные настройки не заменяют работающую конфигурацию. Служебные секреты доступны только серверу. Настройки пространства не показывают этот провайдер.
