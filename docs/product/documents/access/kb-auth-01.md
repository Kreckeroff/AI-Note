# KB-AUTH-01 · Войти локальной учётной записью

Редакция 1 · Базовый контур · [Вход и учётные записи](README.md)

## История

**Сотрудник** хочет открыть своё рабочее пространство с учётной записью, заранее выданной администратором.

## Приёмка

- **К1.** Верные данные открывают авторизованную сессию, обновление страницы сохраняет вход.
- **К2.** При неверных данных сообщение одинаково для существующего и неизвестного аккаунта.

Для первого шага рабочая область представлена защищённой стартовой страницей с именем вошедшего пользователя. [Дизайн](../../design/handoff/spaces-and-account.md#вход) · [SA](kb-auth-01-sa.md) · [Проверки](kb-auth-01-checks.md)

Локальный кандидат прошёл [независимую приёмку](kb-auth-01-qa.md). [Пакет выпуска](kb-auth-01-release.md)
