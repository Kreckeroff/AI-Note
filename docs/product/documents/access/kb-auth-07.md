## История

**Администратор** хочет управлять разрешёнными способами входа.

## Приёмка

- **К1.** Новый SSO-вход прекращается в UI и по прямому адресу, разрешённый локальный вход работает.
- **К2.** При отсутствии альтернативы у администратора изменение отклоняется с объяснением.
