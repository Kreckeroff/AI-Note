# KB-AUTH-06 · Войти через корпоративный SSO

Черновик · Развитие блока · [Вход и учётные записи](README.md)

## История

**Сотрудник** хочет использовать свою корпоративную учётную запись.

## Приёмка

- **К1.** Кнопка корпоративного входа находится на экране входа. После подтверждения у настроенного провайдера открывается назначенный аккаунт.
- **К2.** Неоднозначное сопоставление отклоняется без объединения аккаунтов.
