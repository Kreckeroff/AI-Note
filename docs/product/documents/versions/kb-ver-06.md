# KB-VER-06 · Опубликовать черновик страницы

Черновик · Развитие блока · [Черновики и редакции](README.md)

## История

**Редактор** хочет сделать завершённую редакцию доступной читателям.

## Приёмка

- **К1.** Успешная публикация меняет видимую читателю редакцию и добавляет запись в историю.
- **К2.** При конфликте с более свежей версией чужой текст сохраняется, редактор видит способ продолжить.
