# KB-VER-04 · Восстановить содержимое старой редакции

Редакция 1.0 · Требования подтверждены · [Черновики и редакции](README.md)

## История

**Редактор** хочет откатить ошибочную правку.

## Приёмка

- **К1.** Подтверждение создаёт новую редакцию с прежним названием, точным исходником и его форматом, обложкой. Уже опубликованные версии остаются в истории, а заменённая своя обложка получает новый текущий адрес.
- **К2.** Отсутствие права записи, занятое название, неактуальная основа и сбой оставляют текущую страницу целой. После параллельного изменения нужно подтвердить восстановление заново.
- **К3.** Повтор подтверждённого восстановления возвращает тот же результат даже после последующих сохранений. Отмена не добавляет редакцию.
