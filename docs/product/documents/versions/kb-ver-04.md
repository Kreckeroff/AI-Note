# KB-VER-04 · Восстановить содержимое старой редакции

Черновик · Базовый контур · [Черновики и редакции](README.md)

## История

**Редактор** хочет откатить ошибочную правку.

## Приёмка

- **К1.** Восстановление создаёт новую текущую редакцию с прежним содержимым, позднейшие версии остаются в истории.
- **К2.** Попытка без права записи отклоняется.
