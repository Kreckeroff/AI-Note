# KB-VER-05 · Сохранить личный черновик

Черновик · Развитие блока · [Черновики и редакции](README.md)

## История

**Редактор** хочет продолжить незавершённую правку после возвращения.

## Приёмка

- **К1.** Черновик восстанавливается в согласованной области хранения. Другие читатели видят опубликованный текст.
- **К2.** После потери прав черновик не позволяет отправить запись.
