# KB-VER-03 · Сравнить две редакции

Черновик · Развитие блока · [Черновики и редакции](README.md)

## История

**Редактор** хочет проверить, что изменилось между сохранениями.

## Приёмка

- **К1.** Выбор двух версий показывает изменения текста и заголовка с указанием сравниваемых редакций.
- **К2.** Если версия недоступна, сравнение не раскрывает её содержимое.
