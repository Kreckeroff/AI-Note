# KB-VER-03 · Сравнить две редакции

Редакция 1.0 · Требования подтверждены · [Черновики и редакции](README.md)

## История

**Редактор** хочет проверить, что изменилось между сохранениями.

## Приёмка

- **К1.** Два номера одной страницы показывают разницу заголовков и точного Markdown построчно. Открытое сравнение остаётся на выбранной паре после следующего сохранения. Узкий экран показывает изменения одной лентой.
- **К2.** Недоступность любой редакции закрывает весь результат, включая её заголовок и метаданные.
- **К3.** Проверены пустой исходник, одинаковый текст, изменения пробелов и маркеров, большие документы. При ограничении расчёта оба исходника остаются доступны целиком.
