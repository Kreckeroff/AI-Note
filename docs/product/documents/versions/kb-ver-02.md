# KB-VER-02 · Открыть конкретную редакцию

Редакция 1.0 · Требования подтверждены · [Черновики и редакции](README.md)

## История

**Редактор** хочет сослаться на текст на момент решения.

## Приёмка

- **К1.** Прямая ссылка открывает неизменяемый снимок названия, точного Markdown и обложки, показывает номер и действие «К текущей странице». Чтение работает без JavaScript.
- **К2.** Снятый URL текущей обложки остаётся недоступным. Историческая картинка доступна по её собственному адресу при действующем праве редактирования страницы.
- **К3.** Отзыв права, другой тенант и читатель без права правки не получают содержимое или метаданные снимка. Открытие снимка из редактора сохраняет исходный черновик.
