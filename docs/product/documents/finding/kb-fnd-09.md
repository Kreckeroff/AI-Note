# KB-FND-09 · Вставить ссылку на внутреннюю страницу

Черновик · Развитие блока · [Поиск и связи](README.md)

## История

**Редактор** хочет связать два документа без дублирования.

## Приёмка

- **К1.** Выбор доступной страницы вставляет разрешаемую по ID ссылку, работающую после переименования.
- **К2.** При утрате доступа ссылка не раскрывает закрытые метаданные цели.
