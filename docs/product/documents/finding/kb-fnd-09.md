# KB-FND-09 · Вставить ссылку на внутреннюю страницу

Пакет 1.0 · Старт согласован · [Поиск и связи](README.md)

## История

**Редактор** хочет связать два документа без дублирования.

## Поведение 1.0

- Кнопка «Ссылка» в визуальном режиме и «Исходнике» открывает диалог. При выделении открыт режим «По адресу». Если выделения нет, редактор пространства сразу может искать страницу.
- «Страница пространства» ищет по названию среди доступных для чтения страниц текущего пространства. В результатах видны название страницы и название раздела. Длинная выдача разбита на страницы по 20 результатов.
- Выбор страницы подставляет её название, если подпись пуста. При выделении сохраняется выделенный текст. Подпись можно изменить. После вставки она остаётся обычным текстом Markdown. Ссылка хранит ID среды, пространства и страницы.
- У адресного гостя без доступа к дереву пространства доступна вставка по адресу. Читатель пользуется опубликованными ссылками.

## Приёмка

- **К1.** Текст ссылки вставляется в положение курсора или заменяет выделение в обоих режимах. Отмена возвращает курсор и оставляет черновик в прежнем состоянии. Вставку можно отменить одним действием редактора.
- **К2.** Открытие после переименования страницы ведёт на прежний ID. Подпись остаётся той, которую сохранил автор.
- **К3.** Поиск проверяет чтение в текущем пространстве. В выдачу входят только страницы, совпавшие по названию без учёта регистра. Перед вставкой доступ проверяется повторно. При отзыве прав во время открытого диалога редактор получает сообщение, а ссылка в черновике не появляется.
- **К4.** Если доступ отозвали после сохранения ссылки, переход проверяет права по действующим правилам страницы. Подпись показывается как часть исходного документа.
- **К5.** Вставка ссылки по адресу и глобальный поиск сохраняют свои сценарии. Упоминания в комментариях продолжают работать через собственное меню.

## Проверка пакета 1.0

- На отдельной базе PostgreSQL проверены поиск по названию и границы пространства, доступ читателя, чужой среды и анонимного пользователя, повторная проверка цели и отзыв прав.
- В Chrome проверены вставка по курсору на ширине 320 px, восстановление курсора по Escape, отмена и повтор вставки, исходник с выделением, адресный гость и режим чтения.
- В отдельном экземпляре «Севера» проверен путь от входа до публикации и перехода по ссылке после переименования.
