# KB-FND-02 · Искать по тексту страницы

## История

**Участник** хочет найти материал, если помню только фразу.

## Приёмка

- **К1.** Результат содержит подходящий доступный фрагмент и ведёт на страницу.
- **К2.** Если индекс отстаёт, отзыв права блокирует выдачу источника.
