# KB-COL-05 · Открыть решённую ветку снова

Требования и макет 1.0 согласованы · [Совместная работа](README.md)

## История

**Рецензент** хочет вернуть нерешённое замечание к обсуждению.

## Приёмка

- **К1.** Редактор, владелец или автор темы с текущим правом комментария возвращает решённую тему в активные с прежними сообщениями, привязкой и адресом.
- **К2.** После переоткрытия можно ответить по праву комментария. Сервер отклоняет действие при потере полномочий.
- **К3.** Поздний повтор переоткрытия не отменяет новое решение темы.
