# KB-EXT-07 · Отключить расширение в пространстве

Черновик · Развитие блока · [Расширения редактора](README.md)

## История

**Владелец** хочет перестать использовать расширение и сохранить документы.

## Приёмка

- **К1.** Новые блоки этого типа нельзя добавить, старые показывают согласованное запасное представление.
- **К2.** Исходный текст и данные блока сохраняются для последующего включения.
