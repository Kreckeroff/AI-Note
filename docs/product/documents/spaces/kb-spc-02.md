# KB-SPC-02 · Найти пространство в каталоге

Черновик 0.3 · Базовый контур · [Пространства](README.md)

## История

**Участник** хочет найти нужное пространство среди всех доступных ему рабочих областей. **Администратор организации** хочет видеть все пространства своей организации.

## Приёмка

- **К1.** Из навигации открывается отдельный экран «Пространства». Участник видит свои пространства и те, к которым у него есть доступ на просмотр или редактирование. Из строки можно открыть доступное пространство.
- **К2.** Поиск по названию находит нужное пространство по части имени среди как минимум 100 доступных записей. Экран показывает разные состояния для пустого каталога и поиска без результатов. Действие создания доступно при наличии права.
- **К3.** Обычный участник без доступа не получает название закрытого пространства в каталоге или поиске. После отзыва доступа прежняя ссылка больше не открывает его содержимое.
- **К4.** Администратор видит и открывает для просмотра все пространства своей организации, включая закрытые пространства без членства. Для управления редактированием действуют права пространства.
