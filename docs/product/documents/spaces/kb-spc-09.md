# KB-SPC-09 · Получить личное пространство после регистрации

Черновик · Развитие блока · [Пространства](README.md)

## История

**Новый пользователь** хочет сразу открыть личную рабочую область.

## Приёмка

- **К1.** После первой завершённой регистрации создано одно закрытое пространство с отображаемым именем пользователя и правом владельца. Оно сразу открывается.
- **К2.** При повторе события и следующем входе открывается то же пространство. Переименование владельцем сохраняется.
