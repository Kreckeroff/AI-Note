# KB-SPC-06 · Архивировать пространство

Черновик · Развитие блока · [Пространства](README.md)

## История

**Владелец** хочет убрать неактивную область из повседневной навигации и сохранить её материалы.

## Приёмка

- **К1.** Пространство видно в архиве, документы доступны уполномоченным читателям.
- **К2.** Попытка записи в архивированное пространство получает явную причину отказа.
