# KB-SPC-04 · Изменить описание пространства

## История

**Владелец** хочет объяснить участникам, какие материалы здесь хранятся.

## Приёмка

- **К1.** Сохранённое описание видно участнику на главной пространства.
- **К2.** Участник без права управления может читать описание.
