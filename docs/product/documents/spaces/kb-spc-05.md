# KB-SPC-05 · Передать владение пространством

Черновик · Развитие блока · [Пространства](README.md)

## История

**Владелец** хочет передать администрирование другому участнику.

## Приёмка

- **К1.** Допустимый участник становится владельцем, новый набор полномочий отражён в списке людей.
- **К2.** Операция отклоняется, если получатель больше не состоит в пространстве.
