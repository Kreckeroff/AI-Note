# KB-MD-01 · Изменить и сохранить текст страницы

Пакет 1.0 · Снимок `5e3335ee63a7` принят владельцем · [Markdown-редактор](README.md)

## История

**Редактор** хочет записать или уточнить рабочую информацию.

Владелец подтвердил визуальный ввод текста и абзацев. При изменении страницы в другой сессии редактор сохраняет введённый текст и показывает актуальную версию для ручного совмещения.

## Приёмка

- **К1.** Сохранённый текст одинаково читается после перезагрузки и у другого уполномоченного пользователя.
- **К2.** При сбое записи редактор сохраняет введённый текст для повторной попытки и показывает результат сохранения.
- **К3.** При конфликте версий исходный ввод остаётся в форме, при отмене открывается сохранённый текст.
- **К4.** Право записи повторно проверяется при сохранении. Уполномоченный читатель видит сохранённый текст по прежней постоянной ссылке.
