# KB-MD-02 · Открыть исходный Markdown страницы

Редакция 1.1 · В пакете панели 1.0 · [Markdown-редактор](README.md)

## История

**Редактор** хочет проверить или изменить точную запись Markdown.

Владелец подтвердил прямую визуальную правку форматированного текста и выбрал исходный прототип целиком. Одна кнопка «Исходник» переключает представление текущего черновика в той же панели.

## Приёмка

- **К1.** Редактирование исходника меняет отображение после сохранения, повторное открытие возвращает тот же текст.
- **К2.** Пока ввод не сохранён, переключение представления сохраняет его в редакторе.
- **К3.** Визуальная правка сохраняет формат существующего выделения и исходные символы вне изменённого участка.
- **К4.** При конфликте или временном сбое черновик остаётся доступен в обоих режимах.
