# KB-MD-10 · Добавить чекбокс в документ

Редакция 1.0 · [Расширенный Markdown](kb-md-extended-start.md) · [Markdown-редактор](README.md)

## История

**Редактор** хочет отмечать выполненные пункты списка.

## Приёмка

- **К1.** Отмеченное состояние видно после обновления.
- **К2.** У читателя без редактирования состояние сохраняется при попытке переключить его.
- **К3.** Команда создаёт `- [ ]` в маркированном списке, включая вложенный. Мышь или Space на флажке меняют только маркер этого пункта, фокус остаётся на нём. Флажок имеет доступное имя из текста пункта. Enter добавляет новый пустой флажок, а последний пустой пункт по Enter становится абзацем. В чтении опубликованное состояние видно и без JavaScript.
