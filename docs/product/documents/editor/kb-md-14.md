# KB-MD-14 · Добавить внешнюю ссылку

Редакция 1.0 · [Расширенный Markdown](kb-md-extended-start.md) · [Markdown-редактор](README.md)

## История

**Редактор** хочет направить читателя к внешнему источнику.

## Приёмка

- **К1.** Ссылка показывает выбранный текст и открывает согласованный адрес.
- **К2.** Протокол вне поддерживаемого списка не становится активной ссылкой.
- **К3.** «Ссылка» берёт подпись из выделения в одном редактируемом блоке. Форма сохраняет данные при ошибке адреса, а Escape возвращает выделение без правки. Разрешённый абсолютный HTTP(S)-адрес открывается из чтения в новой вкладке с клавиатуры и без JavaScript. Некорректный исходник виден буквально, адрес существующей ссылки правится через «Исходник».
