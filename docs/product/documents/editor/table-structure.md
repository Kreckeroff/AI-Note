# KB-MD-16 · Структура таблицы 1.0

Редактор меняет размер Markdown-таблицы на странице. Владелец делегировал решения и старт 21 ноября 2026 года в рамках пакета улучшений рабочего пространства. [Исходные правила таблиц](kb-md-16.md) · [Аудит редактора](notion-audit.md)

| Действие | Проверяемое поведение |
| --- | --- |
| Выбрать ячейку | Акцентный контур показывает активную ячейку. Панель у таблицы называет номер строки и столбца. Shift+F10 переводит фокус на её кнопки, Escape возвращает к тексту. |
| Добавить строку или столбец | Пустая строка появляется ниже текущей, столбец — справа. Курсор переходит в новую ячейку в той же колонке или строке. |
| Удалить | Удаление строки данных или столбца оставляет фокус в ближайшей ячейке. У заголовка выключено удаление строки, у единственного столбца — удаление столбца. Таблица может содержать один заголовок. |
| Вернуться к прежней версии | Каждая операция меняет общий Markdown-черновик одним действием редактора и поддерживает Undo и Redo. Кнопка «Сохранить» публикует результат обычным способом. |
| Открыть исходник или читать на телефоне | Сохраняются содержимое соседних блоков, пробелы, форматирование, экранированные вертикальные черты и выравнивание оставшихся столбцов. Внешние разделители добавляются при необходимости для однозначного Markdown. Широкая таблица прокручивается внутри колонки. |
| Открыть страницу с правом чтения | Сервер выводит таблицу с заголовками. Панель структурных действий появляется только в доступном для изменений визуальном редакторе. |

Изменение использует разбор ячеек исходного документа, общую историю черновика и существующую публикацию. Постоянные данные, протокол совместной правки и серверный рендеринг таблиц сохраняют существующий формат. [Операции над исходником](../../../../frontend/src/editor/tableStructure.ts) · [Тесты](../../../../frontend/src/editor/tableStructure.test.mjs)

На клиенте проверены добавление и удаление строки и столбца, клавиатура, выбор пустой ячейки, Undo, ограничения заголовка и режим чтения. Chrome при 320 и 390 px показал ширину табличной области 268 и 333 px и ширину первого заголовка 103 px. На 1360 px таблица заняла 704 px. Проверка формы публикации на тестовом ответе сервера сверяет исходный текст и версию совместного черновика.
