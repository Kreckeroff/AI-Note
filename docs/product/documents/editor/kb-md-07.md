# KB-MD-07 · Создать маркированный список

Черновик · Развитие блока · [Markdown-редактор](README.md)

## История

**Редактор** хочет перечислить элементы без порядка.

## Приёмка

- **К1.** Несколько пунктов отображаются одним списком, Enter продолжает его с новым пунктом.
- **К2.** Пустой последний пункт позволяет выйти из списка.
