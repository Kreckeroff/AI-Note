# Поставка редактора «Севера»

Редакция 1.0 · 18 ноября 2026 года · объём подтверждён владельцем

Согласованный экран [«Документы»](../../design/handoff/editor.md) открывает первую доступную страницу в порядке дерева и показывает её в режиме чтения. Прямая ссылка открывает указанную страницу с проверкой прав. На `4125` работает [проверенный снимок расширенного Markdown `46b9135f22a8`](kb-md-extended-qa.md). Следующий пакет в очереди — обложки страниц.

Владелец выбрал весь экран редактора из макета, включая историю, комментарии, шеринг и совместную правку. Для командных действий нужны сохранение страницы и рабочие права на неё. Для одновременной правки также требуются история и присутствие. Это зависимости согласованного объёма. Поведение каждой микрофичи уточняется перед её разработкой.

## Техническое направление

React отвечает за дерево, чтение и редактирование. Axum проверяет права при каждом чтении и изменении, PostgreSQL хранит страницы и их связи. Адреса зависят от UUID, поэтому переименование и будущие движения в дереве сохранят ссылки.

Предлагаем хранить исходный Markdown как текст. Визуальное редактирование проверяем на реальных примерах из макета. Перед выбором библиотеки проверяем GFM, таблицы, чекбоксы, переключение режимов, команды у курсора и сохранение неподдерживаемых фрагментов при вставке. Последнее нужно для [KB-MD-19](kb-md-19.md). Пользовательский Markdown отображается с обработкой ссылок и безопасным рендерингом.

[Пакет панели редактора 1.0](kb-md-editor-start.md) связывает исходник, заголовки, жирный, курсив, маркированный список и код в строке для общего старта и показа на `4125`.

[Расширенный Markdown 1.0](kb-md-extended-start.md) объединяет оставшиеся карточки Markdown в общий старт и один кандидат для стенда.
