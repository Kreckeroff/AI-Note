# KB-MD-19 · Вставить Markdown из буфера

Редакция 1.0 · [Расширенный Markdown](kb-md-extended-start.md) · [Markdown-редактор](README.md)

## История

**Редактор** хочет перенести размеченный текст без ручной переработки.

## Приёмка

- **К1.** Из поддерживаемого текста создаются согласованные заголовки и списки.
- **К2.** Переход к исходнику возвращает введённый Markdown, включая неподдерживаемые фрагменты.
- **К3.** `Ctrl/⌘+V` сохраняет буквальный текст и действующее оформление. «Вставить как Markdown» принимает простой текст в отдельном поле. Успешная вставка отменяется одним Undo, соседний исходник и прежний буквальный текст сохраняются. Пустое значение и вставка через границу защищённого блока оставляют текущий черновик и выделение доступными для исправления.
