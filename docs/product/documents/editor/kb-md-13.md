# KB-MD-13 · Добавить блок кода

Редакция 1.0 · [Расширенный Markdown](kb-md-extended-start.md) · [Markdown-редактор](README.md)

## История

**Редактор** хочет показать многострочный пример без потери отступов.

## Приёмка

- **К1.** Блок сохраняет переносы, отступы и выбранный язык при повторном открытии.
- **К2.** Неизвестный язык оставляет читаемый текст кода.
- **К3.** «Блок кода» через `/` ставит курсор внутрь. «Код» с многострочным выделением оформляет выделенные строки блоком. Enter сохраняет пустые строки и отступы, `Ctrl/⌘+Enter` возвращает в обычный абзац после блока. Язык можно задать в поле блока. Обратные кавычки внутри примера, табы и пробелы сохраняются после переключения режима и повторного открытия.
