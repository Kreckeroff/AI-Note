## Первый снимок `e9761ce2b5a8`

Снимок собран из 102 файлов. Автоматические проверки React и Rust прошли. На изолированной копии PostgreSQL осталась схема 5, контрольная сумма данных 11 таблиц совпала до и после запуска.

Независимая проверка в Chrome воспроизвела случай с обычной вставкой поверх выделенного жирного слова. Chrome направлял событие во вложенный элемент, черновик оставался прежним, а браузер менял текст напрямую. Остальные браузерные проверки, чтение без JavaScript, сквозное сохранение, права, повтор после `503` и восстановление после `409` прошли.

Три архитектурных ревью направили снимок на исправление. Enter мог переподчинить вложенные пункты, а выбор маркированного списка вызывал переключатель панели. Команда нумерации в «Исходнике» применялась к первой строке выделения. Пробел в конце текста ячейки смещал курсор, форма ссылки меняла скобки и вертикальную черту в адресе, Enter в поле языка мог отправить форму страницы. Отдельные проверки нашли расхождения при замене языка тильдового блока, форматировании прежней буквальной страницы с неровной таблицей и разборе пробельных символов Unicode.

## Второй снимок `fd8b6dcb10d0`

Chrome подтвердил вставку через системный буфер с сохранением жирного начертания и отменой одним Undo. Ввод пробела в ячейке сохранял позицию курсора. Enter в поле «Язык» удерживал фокус и оставлял черновик открытым. Общие фикстуры React и Rust проверили точные адреса ссылок, пробельные символы и границы кода.

Ревью подтвердило сохранение дочернего поддерева при Enter в родительском пункте и применение выбранного стиля списка. В двух случаях требовалось продолжение работы. Enter в пустом вложенном пункте мог отделить следующий вложенный чекбокс. В «Исходнике» пустая строка между выделенными абзацами разделяла их на два списка. Для обоих случаев добавлены регрессии следующего снимка.

## Третий снимок `df1afd4c6b2b`

Внешние пустые строки остаются на месте. Последнее адресное ревью выявило отдельную границу. Пустой верхнеуровневый пункт должен завершать список, когда следом начинается самостоятельный список другого типа.

### Независимая приёмка на `4128`

В Chrome прошли 36 из 36 сценариев, включая обычную вставку через системный буфер, завершённый IME, сохранение и повторное открытие смешанного документа. Другой аккаунт открыл опубликованную страницу с JavaScript и без него. Меню `/` проверено на ширинах 320, 390 и 1280 px, включая разворот и прокрутку у края экрана.

Два сквозных прогона HTTP/PostgreSQL подтвердили права, буквальные страницы, точный исходник, предельные 60 000 кодовых точек, конфликт `409`, оба пути восстановления после `503` и повтор сохранения. Артефакты независимой проверки находятся в `qa-bug-hunt/evidence/kb-md-extended-9e93aa8`.

Контрольная сумма данных всех 11 таблиц совпала до и после прогона на изолированной копии. Тестовые записи удалены. Две исходные просроченные сессии восстановлены в копии после штатной очистки при тестовом входе. Манифест источников совпал до и после QA. Подтверждённых открытых ошибок в проверенной области нет.

После переключения `4125` дополнительная проверка обнаружила, что React оставлял страницу с флажками в серверном режиме. Содержимое читалось, а React-интерфейс не запускался. Chrome возвращал для статичного отключённого флажка разные значения `value` и `defaultValue`, хотя флажок никто не менял. Адресное исправление исключает отключённые поля из определения действий пользователя и сравнивает состояние доступных флажков с исходным состоянием.
