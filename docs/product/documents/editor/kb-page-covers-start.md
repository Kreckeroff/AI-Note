# Обложки страницы «Севера»

Пакет 1.0 · 19 ноября 2026 года · Снимок `9e6c7fad2711` с `4125` принят владельцем

[Макет галереи](../../design/handoff/editor.md#выбрать-обложку) · [Очередь редактора](delivery.md) · [Независимый QA и показ на стенде](kb-page-covers-qa.md)

## Сценарий

Редактор открывает страницу и нажимает «Добавить обложку» или «Изменить обложку». Галерея из согласованного макета показывает «Орбита», «Сияние», «Картография», «Без обложки» и загрузку своей картинки. Для опубликованной или уже выбранной своей картинки видны её предпросмотр и текущая отметка. Действие доступно и в визуальном режиме, и в «Исходнике».

Выбор закрывает галерею, обновляет предпросмотр и возвращает фокус к кнопке обложки. Escape и закрытие галереи оставляют предыдущий выбор в черновике. «Сохранить» публикует итог. «Отмена» возвращает к опубликованной странице. Новые и существующие страницы без выбранной темы открываются с компактным заголовком.

| Карточка | Что получает пользователь |
|---|---|
| [KB-PAG-12 · Готовая обложка](../pages/kb-pag-12.md) | Выбирает одну из трёх тем, видит текущий выбор при повторном открытии галереи и публикует его даже при прежнем Markdown. |
| [KB-PAG-13 · Убрать обложку](../pages/kb-pag-13.md) | Выбирает «Без обложки» для готовой темы или своей картинки. Заголовок становится компактным. Название, Markdown и адрес страницы сохраняются. |
| [KB-FIL-08 · Загрузить свою обложку](../media/kb-fil-08.md) | Выбирает PNG, JPEG или WebP до 5 МБ. Действительный файл виден в черновике и публикуется через «Сохранить». При ошибке остаются предыдущий выбор и текст, а файл можно выбрать снова. |

## Решения пакета

1. Выпускаем все три действия с обложкой одним срезом. Для своей картинки создаём общий приватный слой хранения и выдачи по правам страницы. [KB-FIL-08](../media/kb-fil-08.md) опирается на этот контракт. Вставка изображения внутри Markdown поставляется по [KB-FIL-04](../media/kb-fil-04.md).
2. Продолжаем ручной сценарий `409` редактора. Когда другой редактор сохранил страницу первым, показываем опубликованный вариант и сохраняем текущий текст и выбор в черновике. Если пользователь сам не менял обложку, после подтверждения актуальной основы действует опубликованная обложка. Если обе сессии изменили обложку по-разному, пользователь явно выбирает между опубликованной и черновой, в том числе «Без обложки». Публикация происходит после повторного сохранения.

## Технический контракт

- React связывает галерею с черновиком страницы. Выбор обложки сохраняется при переключении режима. Серверное чтение показывает заголовок и обложку также без JavaScript.
- Axum переиспользует адрес страницы и проверяет доступ на каждую запись и выдачу файла. Загрузка своей картинки проверяет действительный формат, размер до 5 242 880 байт и ограничивает расход памяти при декодировании. Предпросмотр загруженного черновика привязан к автору и странице. Опубликованный файл открывается по видимости именно этой страницы. Отзыв доступа, снятие и замена обложки прекращают выдачу прежних байтов по прямой ссылке на эту обложку.
- PostgreSQL хранит ссылку на текущую обложку и её состояние. Запись текста и обложки выполняется атомарно с существующей проверкой ревизии. Старая форма без поля обложки сохраняет текущий вариант. Сохранение той же пары текста и обложки и повтор уже выполненного запроса возвращают успех без лишней редакции. При `503` редактор удерживает текст, режим и выбранную обложку для повтора.
- Для своей картинки экран использует широкое кадрирование из макета. Слой медиа выдаёт проверенное изображение по маршруту страницы. Оригинальные байты не включаются в HTML или JSON страницы. Неопубликованная картинка другого редактора недоступна читателю.

## Проверки одного кандидата

| Карточка | Обязательные сценарии |
|---|---|
| KB-PAG-12 | Три темы, текущая отметка, возврат фокуса, оба режима, публикация только обложки, независимая вкладка видит прежнюю тему до сохранения. |
| KB-PAG-13 | Снятие готовой и своей обложки, отмена галереи и сеанса, компактный заголовок и исходный текст по прежней ссылке. |
| KB-FIL-08 | Три формата, превышение лимита, повреждённый и неподдерживаемый файл, ошибка загрузки и повтор, замена и отмена. Черновая картинка, чужой тенант, отозванный доступ и старый URL при замене проверяются отдельно. |
| Общие проверки | Сохранение текста и обложки одной редакцией, `409` для двух сессий, `503` и повтор, отсутствие лишней редакции, сохранение действующих страниц после миграции, Chrome на узком экране и чтение без JavaScript. |

Для приёмки на `4125` нужен один пример с готовой темой, загрузкой своей картинки и возвратом к заголовку без обложки. Независимый QA проверяет один зафиксированный срез на отдельной копии PostgreSQL.
