[Согласованный пакет](kb-page-covers-start.md) · [Галерея в макете](../../design/handoff/editor.md#выбрать-обложку)

## Первый снимок `aa2b6f7c42df`

Миграция `0006` на копии PostgreSQL добавила приватный слой обложек. Данные всех 11 прежних таблиц совпали. Прошли 31 тест Rust, 58 модульных тестов редактора и 23 теста приложения и центра фич. Проверки HTTP подтвердили загрузку PNG, JPEG и WebP, атомарную публикацию, отзыв доступа и отказ в выдаче старых изображений.

Ревью выявило два сбоя при ручном разрешении `409`. Публикация только обложки могла вернуть прежний Markdown, а подтверждение актуальной основы могло сбросить новый выбор галереи. Первый сценарий воспроизведён в Chrome на двух учётных записях. Дополнительные замечания касались повтора уже принятой публикации после новых изменений, одинаковых файлов в независимых вкладках, MIME, который браузер не смог определить, и границ модулей хранения.

## Второй снимок `9945cf0f947c`

Сервер различает сохранение обложки и намеренное изменение текста по отпечатку исходного черновика. Неизменённый текст сохраняет актуальную версию при разрешении `409`. Явный выбор из галереи определяется относительно опубликованной обложки и действует при обоих порядках подтверждения основы. Независимые загрузки одинаковых файлов имеют разные UUID. Браузер может передать файл с неопределённым MIME на сервер, который сам проверяет формат по байтам. Общая проверка доступа вынесена в отдельный модуль.

На `4129` прошли 12 сценариев обложек в Chrome, 4 группы HTTP и обе проверки Markdown по HTTP. Полный набор Markdown в Chrome прошёл 37 из 37. Изолированная база совпала с исходной по всем 11 таблицам, три таблицы обложек остались пустыми после удаления тестовых записей. Ревью потребовало расширить обработку позднего повтора для сохранения без изменений и сохранения текста с той же обложкой. Два серверных теста также скорректированы для нативной сборки без React.

## Итоговый снимок `9e6c7fad2711`

Современный редактор подтверждает повтор принятого сохранения после последующих правок. Это проверено для смены обложки, сохранения только текста и сохранения без изменений на актуальной основе. Повтор сохраняет более свежую редакцию. Три архитектурных ревью завершены без открытых замечаний. Прошли 35 тестов Rust в нативной сборке, включая интеграционные с PostgreSQL, 59 тестов редактора, Clippy, rustfmt и TypeScript. Docker-сборка включает React.

Манифест содержит 110 файлов. Образ `sha256:893544babda8f7ec620b24052e05561db9f34fc4bee4d46828a4de11a6cbbb1f` собран по lock-файлам. Миграция `0006` добавляет три таблицы и сохраняет байты всех прежних записей.

Сервер принимает PNG, JPEG и WebP до 5 МБ, до 16 Мп и до 8192 px по стороне. Для показа он сохраняет центрированный JPEG 1000 × 340 без исходных метаданных. Неопубликованная загрузка доступна её автору с правом редактирования 24 часа. Последующие загрузки запускают ограниченную очистку просроченных файлов. Ошибка очистки сохраняет уже принятую загрузку.

### Независимый QA на `4129`

Прошли 14 сценариев обложек в Chrome, пять групп HTTP, оба прежних набора HTTP и все 37 браузерных сценариев Markdown. Отдельно подтверждены реальный повтор после сбоя загрузки и сохранения, снятие после `409`, выбор обоих исходов при правке в двух сессиях и поздний повтор уже принятого запроса. Исходные данные всех 11 таблиц совпали после очистки испытаний. Три новые таблицы пусты. Контрольные суммы 110 файлов и миграции сверены с работающим образом.
