# KB-MD-04 · Выделить текст жирным

Редакция 1.0 · [Пакет панели](kb-md-editor-start.md) · [Markdown-редактор](README.md)

## История

**Редактор** хочет обозначить важную часть фразы.

## Приёмка

- **К1.** Выделенный фрагмент сохраняется и читается жирным.
- **К2.** Повтор команды на выделенном фрагменте в визуальном режиме возвращает обычное начертание. При наборе `**важно**` закрывающий символ применяет формат и оставляет курсор после выделенного слова.
- **К3.** В исходнике команда ставит `**` вокруг выделения и сохраняет его. При одном курсоре он оказывается между маркерами. Правка сохраняет соседние символы и существующий курсив.
