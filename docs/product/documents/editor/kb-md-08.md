# KB-MD-08 · Создать нумерованный список

Редакция 1.0 · [Расширенный Markdown](kb-md-extended-start.md) · [Markdown-редактор](README.md)

## История

**Редактор** хочет описать последовательность шагов.

## Приёмка

- **К1.** Сохранённые пункты читаются в правильном порядке.
- **К2.** При вставке пункта между двумя отображаемая последовательность обновляется.
- **К3.** Команда оформляет текущий или выделенные абзацы одним списком с началом от 1. Enter продолжает список, последний пустой пункт по Enter становится абзацем. При старте с `7)` порядок отсчитывается от 7 и совпадает при чтении. Новый пункт получает следующий видимый номер и текущий тип разделителя. При правке существующие точные маркеры соседних пунктов сохраняются.
