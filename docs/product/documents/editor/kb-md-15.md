# KB-MD-15 · Вставить горизонтальный разделитель

Редакция 1.0 · [Расширенный Markdown](kb-md-extended-start.md) · [Markdown-редактор](README.md)

## История

**Редактор** хочет обозначить границу между частями документа.

## Приёмка

- **К1.** Разделитель остаётся отдельным элементом при чтении и редактировании.
- **К2.** Строка дефисов внутри блока кода остаётся кодом.
- **К3.** «Разделитель» через `/` добавляет самостоятельную строку `---` с пустыми границами или у края документа. Если запрос набран внутри непустого абзаца, текст остаётся в нём, а линия добавляется после. Курсор переходит в абзац после линии. Соседние строки таблицы сохраняются. Операция отменяется одним Undo.
